ELEMENTOS DO HTML

ELEMENTOS DO HTML:

Os elementos do HTML são as partes que formam a estrutura de uma página web. Eles são representados por “tags”, que indicam ao navegador como exibir cada tipo de conteúdo, como títulos, parágrafos, imagens e links. Cada elemento tem uma função específica, ajudando a organizar e dar significado ao conteúdo. Assim, o HTML permite que o navegador entenda e mostre a página de forma correta.

Elementos Básicos

  • DOCTYPE! html- Define a versão do html
  • html- Começa o documento
  • head- Configurações, não aparece na tela
  • body- Tudo que apareçe no site
  • h1- Título
  • p- Parágrafo

Links e Mídias

  • a- cria links para outras páginas
  • img- para adicionar imagens
  • video- para adicionar um video
  • audio- para adicionar audios

Organização e Layout

  • div- container genérico para agrupar elementos
  • span- container em linhas, para pequenos trechos de texto
  • header- cabeçalho da página ou seção
  • footer- rodapé da página ou seção
  • section- define uma seção do conteúdo
  • article- conteúdo independente, como posts ou notícias
Listas
  • ul- para listas não ordenadas
  • ol- para listas ordenadas
  • li- item da lista
